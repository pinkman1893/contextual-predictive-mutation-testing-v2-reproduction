# Contextual Predictive Mutation Testing 实验报告

在本实验中，我复现了 FSE 2023 论文《Contextual Predictive Mutation Testing》中
MutationBERT 的跨项目测试套件预测实验。实验使用作者公开的最终 v2 实验材料，
在本地加载训练好的模型权重、重新生成模型输入并完成测试集推理，验证主要指标能否与论文一致。

## 实验目的与方法

MutationBERT 利用源代码及测试代码的上下文，预测测试能否杀死变异体。
本实验按作者预处理函数，将源方法中的变异前后差异与对应测试方法组合为输入，
采用 CodeBERT 分词，输入长度上限为 1024 tokens，超长输入按作者规则截断。

模型首先输出各个测试杀死变异体的概率。若任意覆盖测试的概率大于 0.25，
则套件将该变异体判定为已杀死，否则判定为存活。套件指标以存活变异体（标签 0）为正类。
阈值预先固定，未依据测试集重新调整。

## 实验步骤

我从官方最终实验包提取模型、原始 Java 测试数据及预处理源码，保留来源及哈希记录。
模型仅提取推理所需张量，逐张量核对原 ZIP 的 CRC32，省略训练优化器状态。
随后直接执行作者未修改的两项预处理函数，重新生成全部模型输入并保留官方原标签。

为兼容当前 Transformers，我按模型张量的实际尺寸重建网络。作者配置声明位置嵌入长度
为 1024，实际位置嵌入权重为 1028 行，因此以实际权重尺寸为准。重建时仅忽略旧版索引缓冲区，
所有模型参数均对应。通过 64 个真实输入，包括最长的 1024-token 输入，比较现代模型与
原序列化模块的历史编码器公式，确认前向计算一致后执行全量推理。

全部概率输出后，我按套件取最大杀死概率并计算评价指标，另用独立整数计数程序检查
混淆矩阵、Precision、Recall、F1、Accuracy，以及测试对到套件的聚合过程。

## 实验结果

| 跨项目套件指标 | Precision | Recall | F1 | Accuracy |
|---|---:|---:|---:|---:|
| 本地 v2 推理 | 0.518519 | 0.652542 | 0.577861 | 0.783654 |
| 论文 Table 3 | 0.52 | 0.65 | 0.58 | 未列出 |

Precision、Recall 和 F1 保留两位小数后分别为 0.52、0.65、0.58，与论文对应实验一致。
套件混淆矩阵为 `[[154,82],[143,661]]`，行表示真实标签，列表示预测标签，顺序为
`[0存活, 1已杀死]`。真实已杀死比例为 0.773077，预测比例为 0.714423，绝对误差为 0.058654。

首次全量输入编码耗时约 57.13 秒，纯全量模型推理耗时 732.72 秒，约 12.21 分钟。
该耗时不含下载、环境建立、模型加载、前向核验和试运行，不能视为论文的变异测试节时结果。
完整逐条预测、机器可读指标及核验文件位于 `results/v2/`。

## 可靠性检查

64 个输入的前向公式对照最大概率绝对差为约 0.00000563。
我将新推理产生的全部 42,687 个概率与作者保存概率逐条比较，最大绝对差为
0.0000243783，平均绝对差约 0.0000004033；阈值 0.25、0.5、0.9 下的分类分歧均为 0。
全部套件最大概率的最大差约 0.00000894，套件阈值 0.25 的分类分歧为 0。

作者保存预测的分片顺序与按文件名排序的本地处理顺序不同。我使用完整分片的真实套件标签
和有序测试对标签序列进行唯一匹配，形成覆盖全部 1,040 个套件的双射。对齐不使用预测概率，
也不改变真实标签。作者概率仅用于核验，正式指标来自本机新产生的预测。

官方套件标签与保留测试对标签的 OR 有 6 处不一致。本实验保留官方标签，未删样本或重新标注。
独立指标计数、聚合、模型和数据校验均通过。

## 实验结论与局限

本实验成功复现最终 v2 模型在跨项目测试套件预测任务上的主要指标，并完成输入编码、
模型推理及套件聚合的核验。结论限于该检查点、数据集和任务的推理复现。

实验没有重新训练模型、重新执行 Major/Defects4J 生成变异体，也没有覆盖同项目评估、
Seshat 对照及论文节时结论。同一套件最优检查点得到的测试对 F1=0.557156 仅为辅助结果，
不能与论文矩阵最优检查点的 F1=0.48 直接比较。前向公式对照运行于当前 PyTorch，
不等同于重建作者完整历史训练环境。
